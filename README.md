# dsh-boot-animation
DSH的启动动画仓库

## 目录说明

| 目录 | 内容 |
|---|---|
| `dsh-boot-splash-main/` | DSH 启动画面插件（核心项目） |
| `mkv-to-mp4/` | 视频转 MP4 工具，用于把视频处理成插件可直接使用的格式 |

> 依赖准备见 `mkv-to-mp4/使用说明.md`。
