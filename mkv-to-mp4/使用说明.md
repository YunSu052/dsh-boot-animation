# MP4 优化工具包 · 使用说明

把视频转成**浏览器能播、且能"边下边播"**的 MP4。适合给 DSH 开机动画用，也适合一般用途。

---

## 〇、开始前：安装依赖（必做）

本工具需要 **Node.js** 和 **ffmpeg** 两个依赖。请先安装：

### 1. Node.js

| 方式 | 操作 |
|---|---|
| **winget（推荐）** | 打开终端执行 `winget install --id OpenJS.NodeJS.LTS -e` |
| **官网下载** | <https://nodejs.org/> ，选 **LTS** 版安装包 |

装完后**关掉再重新打开**终端窗口（否则 PATH 不生效）。

### 2. ffmpeg

| 方式 | 操作 |
|---|---|
| **winget（推荐）** | 终端执行 `winget install --id BtbN.FFmpeg.GPL -e` |
| **手动下载** | <https://github.com/BtbN/FFmpeg-Builds/releases> 选 `win64-gpl` 的 zip，解压后把 `bin` 里的 `ffmpeg.exe` 和 `ffprobe.exe` 放到本文件夹 |
| **其他构建** | <https://www.gyan.dev/ffmpeg/builds/> （选 release full） |
| **官网** | <https://ffmpeg.org/download.html> |

> 工具会**优先使用本文件夹里的** `ffmpeg.exe` / `ffprobe.exe`，找不到才去系统安装位置或 PATH 里找。
> winget 装的 BtbN 版默认在 `C:\Programs\ffmpeg`，也能被自动找到。

## 一、快速开始

### 转码（mkv / HEVC 等 → MP4）

| 我想… | 用哪个 | 输出 |
|---|---|---|
| **画质优先**（保持原分辨率） | **`转原画.bat`** | `<名字>-原画.mp4` |
| **体积优先**（缩到 1080） | **`转1080p.bat`** | `<名字>-1080p.mp4` |

> ⚠️ **两个版本是分开的**，一次只转一个 —— 两个都转很费时，按需要选一个即可。

**三种用法，任选一种：**

1. **拖拽**（最快）：把视频文件拖到 bat 图标上松手
2. **双击**：弹出文件选择框，可多选
3. **终端**：
   ```powershell
   .\转原画.bat "D:\videos\a.mkv"
   ```

### 只做优化（已经是 H.264 的 MP4）

把文件拖到**上面任意一个 bat** 上即可 —— 工具会自动识别：
**H.264 的 MP4 不会重新编码，只做 faststart 优化**，输出 `<名字>-faststart.mp4`。

## 二、为什么要转，而不是改个后缀

### 1. HEVC(H.265) 浏览器放不了

Chromium/Electron **不支持 HEVC**（专利授权原因）。很多 mkv 正是 H.265，
所以**只改封装（`-c copy`）出来照样播不了**，必须**真正重编码**成 H.264。

### 2. `moov` 在尾部会导致"要下完才出画面"

MP4 里 `moov` 是索引（每一帧在哪），`mdat` 是数据。播放器**必须先读到 `moov`** 才知道去哪找帧。

```
未优化：[ftyp][mdat ← 95MB 数据] ......... [moov ← 目录]
                                           ↑ 得一路下到这里才能出首帧

已优化：[ftyp][moov ← 目录][mdat ← 数据]
                ↑ 开头几百 KB 就有目录 ⇒ 立刻出画面
```

工具用 `-movflags +faststart` 让 ffmpeg **直接输出优化好的 MP4**，转码和优化一步到位。

## 三、文件说明

| 文件 | 作用 | 是否必需 |
|---|---|---|
| `转原画.bat` | 转码（原分辨率），拖拽/双击入口 | ✅ |
| `转1080p.bat` | 转码（1080p），拖拽/双击入口 | ✅ |
| `convert.mjs` | 转码引擎（两个 bat 共用） | ✅ |
| `faststart.mjs` | faststart 优化 + 校验（被 convert.mjs 调用） | ✅ |
| `node.exe` | JavaScript 运行时 | 可选，装好 Node.js 就不需要 |
| `ffmpeg.exe` / `ffprobe.exe` | 转码与探测引擎 | 可选，装好 ffmpeg 就不需要 |

> 本仓库出于体积考虑**没有内置** `ffmpeg.exe` / `ffprobe.exe` / `node.exe`，
> 请按「〇、开始前：安装依赖」安装。想省事也可以下载后把 exe 放到本文件夹，实现自包含。

## 四、画质与参数

| 项 | 值 | 说明 |
|---|---|---|
| 视频编码 | H.264 (libx264) | 浏览器通吃 |
| 质量 | `-crf 18` | 数值越小越好；18 视觉上接近无损 |
| 速度 | `-preset medium` | 画质与速度的平衡点 |
| 音频 | **原样复制** | 源是 AAC/MP3 时零损失；否则转 AAC 192k |
| 像素格式 | `yuv420p` | 兼容性最好 |
| 优化 | `-movflags +faststart` | moov 放头部 |

**1080p 版**用 `scale=-2:1080`：高度锁 1080，宽度按原比例自动算（`-2` 保证是偶数）。
所以 4096×2160 的源会变成 **2048×1080**，而不是 1920×1080 —— 这是**正确的**，保持了原始宽高比。

## 五、常见问题

**Q：输出文件在哪？**
和原视频**同一个文件夹**，文件名加 `-原画` / `-1080p` / `-faststart` 后缀。

**Q：会覆盖原视频吗？**
**不会。** 工具全程只读输入；输出已存在时默认**拒绝**（bat 里带了 `-y` 才会覆盖）。

**Q：提示"找不到 node.exe"？**
装 Node.js（`winget install --id OpenJS.NodeJS.LTS -e`，或官网 <https://nodejs.org/>），
**重新打开**终端后重试；也可以把 `node.exe` 放到本文件夹。

**Q：提示"找不到 ffmpeg"？**
装 ffmpeg（`winget install --id BtbN.FFmpeg.GPL -e`，或从
<https://github.com/BtbN/FFmpeg-Builds/releases> 下载 `win64-gpl` 解压），
**重新打开**终端后重试；也可以把 `ffmpeg.exe` + `ffprobe.exe` 放到本文件夹。

**Q：转完还是播不了？**
检查是不是**没转码**（比如只改了后缀名）。用 `转原画.bat` 走一遍真正的转码。

**Q：为什么 1080p 是 2048×1080 而不是 1920×1080？**
源视频是 4096:2160 的特殊比例，工具保持了原始宽高比，没有拉伸。

**Q：`.mkv` 和 `.mp4` 能一起拖吗？**
可以。工具会逐个判断：需要转码的转码，已是 H.264 的只做优化。

**Q：能转别的格式吗？**
常见格式都行（mkv / webm / avi / mov / m4v…）。ffmpeg 支持的它基本都支持。

**Q：想改用更小体积？**
编辑 `convert.mjs`，把 `-crf 18` 改成 `-crf 23`（更小）或 `28`（更小但画质下降）。

**Q：转得慢，能加速吗？**
默认用纯软件编码（libx264），任何电脑都能跑。若显卡支持 NVENC，
可在 `convert.mjs` 里把 `libx264` 换成 `h264_nvenc`，速度会快很多（需要较新驱动）。

## 六、命令行高级用法

不想用 bat 时，可以直接调 `convert.mjs`（需先安装 Node.js）：

```powershell
# 原画（默认）
node .\convert.mjs "视频.mkv" -y

# 1080p
node .\convert.mjs "视频.mkv" --1080 -y

# 只做 faststart 优化（对已有 MP4）
node .\faststart.mjs "视频.mp4" -y
```

| 选项 | 作用 |
|---|---|
| `--orig` | 出原画（默认） |
| `--1080` | 出 1080p |
| `-y, --yes` | 覆盖已存在的输出 |
| `-h, --help` | 帮助 |

## 七、故障排查

**窗口一闪而过**
用终端运行，或在 bat 末尾已加了 `pause`（正常会停住等你按键）。

**中文显示乱码**
bat 已设 `chcp 65001`（UTF-8）。若仍有问题，说明终端字体不支持，不影响功能。

**装了 ffmpeg 还是找不到**
先关掉终端窗口再重新打开（PATH 不会热更新）；或在终端执行
`ffmpeg -version` 确认能跑通，再重试。
